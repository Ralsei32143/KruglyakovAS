Мобильное приложение для автоматизации работы железнодорожной бригады в структуре РЖД, которое обеспечивает функционал для трёх ролей: бригадир может создавать задания, просматривать список заданий с возможностью редактирования и удаления, а также формировать отчёты; работник видит свои активные и выполненные задания, может приступить к выполнению и отправить отчёт с указанием статуса, проблем и комментариев; администратор управляет пользователями — добавляет, редактирует и удаляет их, задавая роли и логины; все данные хранятся внутри приложения, а интерфейс выполнен в едином корпоративном стиле РЖД с красными акцентами и строгой навигацией между экранами.
